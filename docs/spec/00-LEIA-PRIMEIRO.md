Este diretório contém a especificação de desenvolvimento do site oficial / EPK digital do artista **LENT (João Quaresma)**.

## Arquivos obrigatórios

Leia nesta ordem:

1. `docs/spec/01-PROMPT-MESTRE.md`
2. `docs/spec/02-FIDELIDADE-VISUAL.md`
3. `docs/spec/03-INSTRUCAO-EXECUCAO.md`
4. `docs/spec/04-CRITERIOS-DE-ACEITE.md`

Referências visuais:

- `docs/reference/site-admin-reference.png` — **DESIGN MASTER** do site público e do painel administrativo.
- `docs/reference/lent-original.jpg` — fotografia original do artista.

## Regra de prioridade

Em caso de dúvida:

1. A imagem `site-admin-reference.png` define a composição visual.
2. `02-FIDELIDADE-VISUAL.md` define regras de UI/design.
3. `01-PROMPT-MESTRE.md` define arquitetura, funcionalidades e regras de negócio.
4. `03-INSTRUCAO-EXECUCAO.md` define como executar o trabalho.
5. `04-CRITERIOS-DE-ACEITE.md` define quando o projeto pode ser considerado concluído.

Não reinterpretar o design como uma landing page genérica. O objetivo é implementar funcionalmente a interface aprovada com alta fidelidade visual.
